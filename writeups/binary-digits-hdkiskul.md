# Binary Digits - Forensics


## Approach
- ran file digits.bin in terminal to read file info
- ran strings digits.bin and got a long line of 0s and 1s
- tried finding for bin to text converters
- found cyberchef
- it recognised the .bin was to be converted into a .jpeg

## Solution
- use cyberchef to convert the given binary string to a .jpeg
- the jpeg has the flag written in it

## Flag
picoCTF{h1dd3n_1n_th3_b1n4ry_a59b2b0a}

## Takeaway
Remember to use cyberchef when need to decode something
